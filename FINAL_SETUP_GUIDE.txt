================================================================================
TROUBLESHOOTING
================================================================================

Issue: Port 8000 already in use
  Solution: Change port in run_backend.bat or kill process using port 8000

Issue: Crawl4AI timeout
  Solution: Increase timeout in sam_world_hunter.py (page_timeout parameter)

Issue: Affiliate links not working
  Solution: Update affiliate IDs in .env file

Issue: Database connection error
  Solution: Ensure PostgreSQL is running on localhost:5432

Issue: Redis connection error
  Solution: Ensure Redis is running on localhost:6379
