# Token-saving workflow

- उत्तर संक्षिप्त आणि मुद्देसूद ठेवा.
- शोधासाठी आधी नेमका file/path आणि लहान संबंधित section वाचा; संपूर्ण मोठ्या फाइल्स अनावश्यक वाचू नका.
- बदलांसाठी minimal diff वापरा; असंबंधित reformat करू नका.
- कमांड output मधून फक्त error, status आणि आवश्यक ओळी summarize करा.
- मोठी अंमलबजावणी करण्यापूर्वी 2–4 टप्प्यांचा छोटा plan द्या.
- पूर्ण झाल्यावर बदललेल्या फाइल्स आणि verification एका छोट्या summary मध्ये सांगा.
