संकल्पना: ग्राहकाला कोणता कार्ड डिस्काउंट, कूपन कोड आणि गिफ्ट कार्ड एकत्र वापरल्यास सर्वाधिक फायदा होईल हे गणित मांडणे कठीण जाते.

ॲपमधील ऑटोमेशन: ॲपमधील ब्राउझरने किंवा एक्स्टेंशनने चेकआउट पेजवर एकाच क्लिकमध्ये ५०+ कूपन कॉम्बिनेशन्स, बँक कार्ड ऑफर्स आणि उपलब्ध कॅशबॅकची चाचणी घेऊन सर्वोत्तम आणि सर्वात स्वस्त कॉम्बिनेशन ऑटो-अप्लाय (Auto-Apply) केले पाहिजे.

3. पूल खरेदी / सोशल ग्रुप बायिंग (Social Group Buying)
संकल्पना: घाऊक (HoleSale) व्यापारी जेव्हा मोठ्या प्रमाणात ऑर्डर घेतात, तेव्हा ते २०% ते ४०% अतिरिक्त सूट देतात. (चीनमधील Pinduoduo ॲप याच मॉडेलवर चालते).

ॲपमधील ऑटोमेशन: जर तुमच्या ॲपवर १० वेगवेगळ्या युजर्सना एकच लॅपटॉप किंवा हेडफोन घ्यायचा असेल, तर ॲप त्यांना एका 'पूल' (Pool) मध्ये एकत्र करेल आणि थेट ब्रँड किंवा डिस्ट्रीब्युटरशी संपर्क साधून बल्क डिस्काउंटमध्ये ती ऑर्डर पूर्ण करेल.

4. एआय नेगोशिएशन बॉट (AI Bargaining Agent)
संकल्पना: D2C (Direct-to-Consumer) ब्रँड्सच्या वेबसाइटवर जर तुम्ही कस्टमर सपोर्ट चॅटमध्ये जाऊन "मला आणखी डिस्काउंट हवा आहे" असे विचारले, तर ते १०% चे स्पेशल कूपन देतात.

ॲपमधील ऑटोमेशन: ॲपमधील AI चाटबॉट बॅकएंडला मर्चंटच्या चॅटशी कनेक्ट होऊन युजरच्या वतीने संवाद साधेल आणि रिअल-टाइममध्ये ५% ते १५% चा अतिरिक्त कूपन कोड मिळवून देईल.

5. स्टॉक मार्केटसारखे 'ऑटो-बाय' (AI Price Prediction & Auto-Buy)
संकल्पना: वस्तूची किंमत रात्री २ वाजता किंवा फ्लॅश सेल दरम्यान अचानक खूप कमी होते, पण युजर नेहमी स्क्रीनवर लक्ष ठेवू शकत नाही.

ॲपमधील ऑटोमेशन: युजरने त्याची टार्गेट किंमत सेट करून ठेवायची (उदा. "हा फोन जेव्हा ₹१५,००० चा होईल तेव्हा खरेदी करा"). ॲप किमतीवर लक्ष ठेवेल आणि किंमत घसरताच युजरच्या पूर्व-परवानगीने ऑटोमॅटिकली ऑर्डर बुक करेल.

6. ओपन-बॉक्स आणि क्लिअरन्स स्कॅनर (Open-Box & Clearance Aggregator)
संकल्पना: Amazon Warehouse, Flipkart ReGlobe, आणि Vijay Sales Clearance मध्ये केवळ बॉक्स उघडलेल्या किंवा किरकोळ पॅकेजिंग खराब असलेल्या वस्तू ३०% ते ६०% स्वस्तात मिळतात, पण त्या शोधणे कठीण असते.

ॲपमधील ऑटोमेशन: सर्व ई-कॉमर्स प्लॅटफॉर्मवरील व्हॅलिडेटेड 'Open-Box' आणि 'Refurbished' वस्तूंचा रिअल-टाइम डेटा गोळा करून एकाच स्क्रीनवर युजरला दाखवणे.

नो कार्ड डेटा स्टोअर (No Card Storage): आपण युझरचे बँक डिटेल, पासवर्ड किंवा क्रेडिट कार्ड नंबर ॲपमध्ये कधीही सेव्ह करत नाही.

सुरक्षित लॉगिन (OTP/Google Login): युझरचे लॉगिन हे Google Sign-In किंवा मोबाइल OTP द्वारे होईल (Firebase / Supabase द्वारे, जे पूर्णपणे सुरक्षित आणि मोफत आहे).

SSL Enryption: ॲप आणि सर्व्हरमधील सर्व डेटा एन्क्रिप्टेड (HTTPS) असेल.

५. झिरो बजेट मार्केटिंग (पैसे नसताना ट्रॅफिक कसे आणायचे?)
सुरवातीला जाहिरातींवर १ रुपयाही खर्च न करता हजारो युझर्स आणण्यासाठी 'व्हायरल आणि सेंद्रिय (Organic) पद्धती' वापरायच्या:

A. व्हॉट्सॲप आणि टेलिग्राम डील ग्रुप्स (WhatsApp / Telegram Strategy)
आजकाल प्रत्येक गावात आणि शहरात "Loot Deals" चे टेलिग्राम आणि व्हॉट्सॲप ग्रुप्स खूप चालतात.

आपल्या AI ला ऑटो-पोस्टिंगवर लावायचे. AI दररोजच्या सर्वात मोठ्या ५ सवलतीच्या डिल्सचा आकर्षक मेसेज (फोटो + लिंकसह) टेलिग्राम आणि व्हॉट्सॲप ग्रुप्सवर ऑटोमॅटिक पोस्ट करेल.

B. इन्स्टाग्राम रील्स आणि युट्यूब शॉट्स (Content Marketing)
'हॅक आणि पोलखोल' व्हिडिओ:

उदा. "Amazon वर सेलमध्ये हा फोन ₹१५,००० ला मिळतोय पण आमचा AI सांगतोय की २ दिवसांपूर्वी याची किंमत ₹१३,००० होती! खोट्या डिस्काउंटला बळी पडू नका, बायोग्राफीमधील 'Shopping AI' वापरून खरी किंमत तपासा."

असे व्हिडिओ इन्स्टाग्रामवर खूप वेगाने व्हायरल होतात.

C. 'शेअर करा आणि कॅशबॅक मिळवा' (Referral Loop)
"तुमच्या ५ मित्रांना व्हॉट्सॲपवर हे ॲप शेअर करा आणि तुमच्या पहिल्या खरेदीवर ₹५० थेट बँक खात्यात मिळवा." युझर्स स्वतःहून ॲप मित्रांना पाठवतील.

📊 थोडक्यात सारांश (Summary)
विश्वास: पेमेंट Amazon/Flipkart वरच होणार असल्याने युझरचा १००% विश्वास बसतो.

सुरक्षा: आपण फक्त विश्वसनीय ब्रँड्सच दाखवणार आणि कोणताही पासवर्ड सेव्ह करणार नाही.

काम: ९०% काम AI करेल, तुम्हाला फक्त १०% मार्केटिंग आणि मॉनिटरिंग करायचे आहे.

मार्केटिंग: इन्स्टाग्राम रील्स, व्हॉट्सॲप ऑटो-शेअरिंग आणि रेफरल ट्रिक्सने ₹० खर्चात ट्रॅफिक येईल.

झिरो-बजेट मार्केटिंगसाठी पहिल्या महिन्याचा 'डेली मार्केटिंग प्लॅन' कसा असावा हे जाणून घ्यायचे आहे का?

Yes

एस

'Shopping AI' ॲप किंवा व्हॉट्सॲप बॉटसाठी जाहिरातींवर एक रुपयाही खर्च न करता पहिल्या ३० दिवसांत १,००० हून अधिक ॲक्टिव्ह युझर्स मिळवण्यासाठीचा टप्प्याटप्प्याने (Step-by-Step) तयार केलेला झिरो-बजेट मार्केटिंग प्लॅन खालीलप्रमाणे आहे.

🗓️ आठवडा १: पायाभूत तयारी आणि सोशल मीडिया सेट-अप (Setup & Content Bank)
या आठवड्यात ॲपचा प्रचार सुरू करण्याआधी आवश्यक असणारे सोशल मीडिया हँडल्स तयार करायचे आहेत:

दिवस १-२: हँडल्स तयार करणे

Instagram Page, Telegram Channel, YouTube Channel आणि WhatsApp Community तयार करा (नाव: Shopping AI).

बायोमध्ये (Bio) स्पष्ट संदेश लिहा: "ई-कॉमर्स साइट्सवरील खोटे डिस्काउंट ओळखा आणि एआयच्या मदतीने सर्वात स्वस्त डील मिळवा!"

दिवस ३-५: ५ ते १० रील्स/शॉर्ट्सचे शूटिंग

स्क्रीन रेकॉर्डिंग करून ॲप/बॉटचा प्रत्यक्ष वापर दाखवणारे ५ ते १० छोटे व्हिडिओ बनवा.

कन्सेप्ट: "Amazon वर हा फोन ₹१५,००० चा वाटतोय? पण आमच्या Shopping AI ने तपासले तेव्हा २ दिवसांपूर्वी याची किंमत ₹१३,००० होती!"

दिवस ६-७: ऑटो-शेअरिंग सेट करा

Telegram Channel वर ऑटो-पोस्टिंग सेट करा, जेणेकरून ॲपवर आलेल्या सर्वोत्तम डिल्स थेट टेलिग्रामवर पोस्ट होतील.

🗓️ आठवडा २: सॉफ्ट लाँच आणि कम्युनिटी मार्केटिंग (१ ते १०० युझर्स)
पहिल्या १०० युझर्ससाठी थेट विक्री न करता 'मदत' (Value Addition) करण्यावर भर द्या:

दिवस ८-१०: मित्र आणि कौटुंबिक नेटवर्क (Warm Outreach)

तुमच्या जवळच्या १०० लोकांना किंवा व्हॉट्सॲप ग्रुप्सवर मेसेज पाठवा:

"मी ऑनलाइन खरेदी करताना पैसे वाचवणारा एक मोफत AI बॉट/ॲप 'Shopping AI' बनवला आहे. तुम्ही कोणतीही वस्तू घेण्याआधी त्याची लिंक पाठवून किंमत नक्की तपासा. वापरून बघा आणि मला फीडबॅक द्या!"

दिवस ११-१४: ऑनलाइन कम्युनिटीज (Reddit, Facebook, Telegram)

Reddit (r/india, r/DealsIndia), Facebook Shopping Groups, आणि टेलिग्राम डील ग्रुप्स जॉईन करा.

लोकांच्या प्रश्नांना उत्तरे द्या: जर कोणी "सर्वोत्तम ५G फोन कोणता?" किंवा "हा लॅपटॉप स्वस्त कुठे मिळेल?" असे विचारत असेल, तर त्यांना तुमच्या Shopping AI द्वारे काढलेला डेटा शेअर करा.

🗓️ आठवडा ३: व्हायरल कंटेंट इंजिन (१०० ते ५०० युझर्स)
आता व्हिडिओं द्वारे वेगाने नवीन युझर्स आणण्याची वेळ आहे:

दिवस १५-२१: रोज २ रील्स/शॉर्ट्स पोस्ट करणे

सकाळी ११ वाजता (शॉर्ट्स): "३ सीक्रेट ट्रिक्स ज्या ई-कॉमर्स कंपन्या तुमच्यापासून लपवतात."

संध्याकाळी ७ वाजता (इन्स्टाग्राम रील): "बँक कार्ड + कूपन वापरून ॲपलचे एअरपॉड ५०% स्वस्तात कसे घेतले?" (Shopping AI चा वापर दाखवा).

व्हायरल हुक्स (Hooks):

"जर तुम्ही आजच ऑनलाईन शॉपिंग करत असाल, तर हा व्हिडिओ आधी पाहा!"

"सेलमध्ये खरंच डिस्काउंट मिळतो की फसवणूक होते? AI कडून पोलखोल!"

🗓️ आठवडा ४: रेफरल लूप आणि ऑटो-ग्रोथ (५०० ते १,०००+ युझर्स)
आता युझर्सनाच तुमच्या ॲपची जाहिरात करायला लावा (Viral Loop):

दिवस २२-२५: रेफरल फीचर चालू करा (Refer & Unlock)

ॲप किंवा बॉटवर मेसेज सेट करा:

"जर तुम्हाला कोणत्याही वस्तूची किंमत आणखी घसरल्यावर थेट व्हॉट्सॲप अलर्ट हवा असेल, तर ही लिंक तुमच्या ३ मित्रांना पाठवा आणि व्हीआयपी अलर्ट्स अनलॉक करा!"

दिवस २६-३०: मायक्रो-इन्फ्लुएन्सर्सशी सहकार्य (Barter Collaboration)

५,००० ते २०,००० फॉलोअर्स असलेल्या टेक किंवा शॉपिंग इन्स्टाग्राम पेजेसना मेसेज करा.

त्यांना पैशांऐवजी सांगून बघा: "आम्ही तुमचा प्रॉमो कोड ॲपमध्ये हायलाइट करू किंवा तुमच्या फॉलोअर्ससाठी मोफत प्राईस-ट्रॅकर टूल देऊ."

📌 यशासाठी ३ सुवर्ण नियम (Golden Rules)
सातत्य (Consistency): पहिल्या १० व्हिडिओंवर कमी व्ह्यूज आले तरी थांबायचे नाही. इन्स्टाग्राम आणि युट्यूबचे अल्गोरिदम १५ ते २० व्हिडिओंनंतर कंटेंट पुश करायला सुरुवात करतात.

विश्वासूपणा (Transparency): जिथे खरोखर फायदा होतोय तिथेच प्रॉडक्ट सुचवा. खोट्या ऑफर्स कधीही दाखवू नका.

कस्टमर फीडबॅक: सुरुवातीच्या युझर्सना थेट मेसेज करून विचारा की ॲप वापरताना काय अडचण येतेय आणि त्यानुसार सुधारणा करा.

पहिल्या ५ इन्स्टाग्राम रील्ससाठी स्क्रिप्ट (Short Video Scripts) लिहून हव्या आहेत का?

Yes

'Shopping AI' च्या प्रसारासाठी इन्स्टाग्राम रील्स आणि युट्यूब शॉट्स (Reels & Shorts) साठी पहिल्या ५ उच्च-प्रतिसादात्मक (High-Converting) व्हायरल स्क्रिप्ट्स खालीलप्रमाणे आहेत.

या स्क्रिप्ट्स अशा प्रकारे डिझाइन केल्या आहेत ज्या पहिल्या ३ सेकंदातच प्रेक्षकांचे लक्ष वेधून घेतील (Viral Hook) आणि त्यांना ॲप/बॉट वापरण्यास प्रवृत्त करतील.

🎥 रील १: खोट्या डिस्काउंटची पोलखोल (Fake Discount Detector)
विषय: सेलमध्ये होणाऱ्या खोट्या डिस्काउंटपासून युझर्सचा बचाव करणे.

विझ्युअल/व्हिडिओ: हातात फोन धरून ॲमेझॉन/फ्लिपकार्ट उघडून दाखवणे.

[००:०० - ००:०३] हुक (Hook - जोराने व स्पष्ट बोला):

"ऑनलाइन सेलमध्ये ५०% ऑफ पाहून लगेच खरेदी करू नका! या खोट्या डिस्काउंटला तुम्ही रोज बळी पडताय!"

[००:०३ - ००:२०] बॉडी (Body):

"पहा, Amazon वर हा फोन ₹१५,००० ला ५०% ऑफ दाखवतोय. पण जेव्हा मी याची लिंक Shopping AI मध्ये टाकली, तेव्हा AI ने ६ महिन्यांचा प्राईस आलेख दाखवला... आणि बघा, सेल सुरू होण्याच्या अवघ्या २ दिवसांपूर्वी याची खरी किंमत ₹१३,००० च होती! म्हणजे कंपन्यांनी आधी किंमत वाढवली आणि मग ५०% डिस्काउंट दाखवून तुम्हाला उल्लू बनवले!"

[००:२० - ००:३०] सीटीए (Call to Action):

"कोणत्याही खोट्या डिस्काउंटला बळी पडू नका! खरेदी करण्यापूर्वी बायोमधील Shopping AI च्या लिंकवर जाऊन खरी किंमत नक्की तपासा. व्हिडिओ मित्रांना नक्की शेअर करा!"

🎥 रील २: व्हॉट्सॲप १-क्लिक ट्रॅकर (WhatsApp Bot Feature)
विषय: कोणतेही ॲप न घेता थेट व्हॉट्सॲपवर स्वस्त वस्तू शोधणे.

विझ्युअल: स्क्रीन रेकॉर्डिंग – व्हॉट्सॲप चॅटवर लिंक पाठवणे व उत्तर येणे.

[००:०० - ००:०३] हुक (Hook):

"कोणतेही नवीन ॲप डाउनलोड न करता ऑनलाईन वस्तू सर्वात स्वस्तात कशी शोधायची? ही सिक्रेट ट्रिक पाहा!"

[००:०३ - ००:२०] बॉडी (Body):

"तुम्हाला ॲमेझॉन किंवा फ्लिपकार्टवर कोणतीही वस्तू आवडली — जसे की हे शूज. फक्त त्याची लिंक कॉपी करा आणि आमच्या Shopping AI च्या व्हॉट्सॲप नंबरवर पेस्ट करा. अवघ्या ५ सेकंदात हा AI बॉट तुम्हाला इंटरनेटवरील १००+ साइट्स स्कॅन करून सांगेल की हे शूज इतर कुठल्या साइटवर आणखी ₹८०० स्वस्त मिळतात!"

[००:२० - ००:३०] सीटीए (Call to Action):

"आत्ताच हा व्हॉट्सॲप नंबर सेव्ह करा! नंबर आणि लिंक आमच्या इन्स्टाग्राम बायोमध्ये दिली आहे. आजच वापरून बघा!"

🎥 रील ३: बँक कार्ड + कूपन हॅक (Stacking Strategy)
विषय: एकाच वेळी ५ डिस्काउंट वापरून जास्त पैसे वाचवणे.

विझ्युअल: चेहऱ्यावर आश्चर्यकारक हावभाव आणि लॅपटॉप खरेदीचा सीन.

[००:०० - ००:०३] हुक (Hook):

);

import redis
import json
import os

REDIS_HOST = os.getenv("REDIS_HOST", "localhost")
REDIS_PORT = int(os.getenv("REDIS_PORT", 6379))

# Redis कनेक्शन स्थापित करणे
redis_client = redis.Redis(host=REDIS_HOST, port=REDIS_PORT, db=0, decode_responses=True)

def get_cached_product(url: str):
    """१ तासाच्या आत कॅश केलेला डेटा असल्यास मिळवा"""
    data = redis_client.get(url)
    if data:
        return json.loads(data)
    return None

def set_cached_product(url: str, data: dict, ttl: int = 3600):
    """१ तासाच्या TTL (Time To Live) सह डेटा कॅश करा"""
    redis_client.setex(url, ttl, json.dumps(data))

from playwright.async_api import async_playwright
import re

async def scrape_amazon(page, url: str) -> dict:
    """Amazon India साठीचा स्क्रॅपर"""
    await page.goto(url, wait_until="domcontentloaded", timeout=60000)
    
    # Title
    title_el = await page.locator("#productTitle").first.text_content() if await page.locator("#productTitle").count() > 0 else "N/A"
    title = title_el.strip() if title_el else "N/A"
    
    # Price
    price_el = await page.locator(".a-price-whole").first.text_content() if await page.locator(".a-price-whole").count() > 0 else "0"
    current_price = float(re.sub(r'[^\d.]', '', price_el.replace(',', ''))) if price_el else 0.0
    
    # MRP / Original Price
    mrp_el = await page.locator(".a-text-price .a-offscreen").first.text_content() if await page.locator(".a-text-price .a-offscreen").count() > 0 else str(current_price)
    mrp = float(re.sub(r'[^\d.]', '', mrp_el.replace(',', ''))) if mrp_el else current_price
    if mrp < current_price:
        mrp = current_price

    # Image
    image_url = await page.locator("#landingImage").get_attribute("src") if await page.locator("#landingImage").count() > 0 else ""

    # Rating
    rating_el = await page.locator("i.a-icon-star span").first.text_content() if await page.locator("i.a-icon-star span").count() > 0 else "0"
    rating_match = re.search(r'([\d.]+)', rating_el)
    rating = float(rating_match.group(1)) if rating_match else 0.0

    # Stock Status
    availability = await page.locator("#availability").text_content() if await page.locator("#availability").count() > 0 else ""
    stock_status = "In Stock" if "In stock" in availability or "In Stock" in availability else "Out of Stock"

    return {
        "title": title,
        "current_price": current_price,
        "mrp": mrp,
        "store_name": "Amazon India",
        "image_url": image_url,
        "rating": rating,
        "stock_status": stock_status
    }

        context = await browser.new_context(
            user_agent="Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/122.0.0.0 Safari/537.36"
        )
        page = await context.new_page()

        try:
            if "amazon" in url.lower():
                data = await scrape_amazon(page, url)
            elif "flipkart" in url.lower():
                data = await scrape_flipkart(page, url)
            else:
                raise ValueError("सध्या फक्त Amazon आणि Flipkart चे URLs समर्थित आहेत.")
        finally:
            await browser.close()

        # सवलत टक्का आणि बनावट सवलत (Fake Discount) तपासणे
        discount = 0.0
        if data["mrp"] > 0:
            discount = ((data["mrp"] - data["current_price"]) / data["mrp"]) * 100
        
        # जर MRP खूप फुगवून दाखवला असेल (उदा. ८०% पेक्षा जास्त सवलत किंवा MRP मूळ किंमतीपेक्षा ३ पट जास्त), तर fake discount फ्लॅग True करा.
        is_fake_discount = discount > 80.0 or (data["mrp"] > data["current_price"] * 3)

        data["discount_percentage"] = round(discount, 2)
        data["is_fake_discount"] = is_fake_discount

        return data

from app.schemas.product import ProductAnalyzeRequest, ProductAnalyzeResponse
from app.services.cache import get_cached_product, set_cached_product
from app.services.scraper import scrape_product

app = FastAPI(
    title="Shopping AI Backend API",
    version="1.0.0",
    description="Product price scraping and analysis backend service"

@app.post("/api/v1/product/analyze", response_model=ProductAnalyzeResponse)
async def analyze_product(request: ProductAnalyzeRequest):
    url = request.url.strip()
    
    if not url:
        raise HTTPException(status_code=400, detail="URL देणे अनिवार्य आहे.")

    # १. आधी Redis Cache तपासा
    cached_data = get_cached_product(url)
    if cached_data:
        cached_data["cached"] = True
        return cached_data

    # २. कॅशमध्ये उपलब्ध नसल्यास ताजी माहिती स्क्रॅप करा
    try:
        product_data = await scrape_product(url)
        product_data["cached"] = False
        
        # ३. मिळालेला डेटा १ तासासाठी (3600 seconds) Redis मध्ये सेव्ह करा
        set_cached_product(url, product_data, ttl=3600)
        
        return product_data
    except Exception as e:
        raise HTTPException(status_code=500, detail=f"स्क्रॅपिंगदरम्यान त्रुटी आली: {str(e)}")

// URL शोधण्यासाठी Regex (Amazon & Flipkart)
const URL_REGEX = /(https?:\/\/[^\s]+)/g;

/**
 * पाठवलेल्या मेसेजमधून पहिला वैध URL शोधून काढतो
 */
function extractUrl(text) {
    if (!text) return null;
    const matches = text.match(URL_REGEX);
    return matches ? matches[0] : null;
}

/**
 * Backend कडून मिळालेल्या डेटावरून सुंदर WhatsApp मेसेज फॉरमॅट करणे

function formatResponse(data, rawUrl) {
    const discountEmoji = data.is_fake_discount ? '⚠️ *Fake Discount Warning!*' : '🔥 *Great Deal!*';
    const fakeDiscountNotice = data.is_fake_discount
        ? '\n⚠️ *टीप:* या वस्तूची मूळ किंमत (MRP) कृत्रिमरीत्या वाढवून सवलत मोठी दाखवली आहे.'
        : '';

    return `🛍️ *Shopping AI - Price Analysis* 🛍️

📦 *वस्तू:* ${data.title}
🏪 *स्टोअर:* ${data.store_name}
⭐ *रेटिंग:* ${data.rating ? data.rating + ' / 5' : 'उपलब्ध नाही'}
📦 *स्टॉक स्टेटस:* ${data.stock_status}

----------------------------------
💰 *सध्याची किंमत:* ₹${data.current_price.toLocaleString('en-IN')}
🏷️ *मूळ किंमत (MRP):* ₹${data.mrp.toLocaleString('en-IN')}
📉 *सवलत:* ${data.discount_percentage}% OFF
----------------------------------
${discountEmoji}${fakeDiscountNotice}

🔗 *मूळ लिंक:* ${rawUrl}
${data.cached ? '\n⚡ _(Cache मधून त्वरीत दाखवलेली माहिती)_' : ''}

🤖 *Shopping AI Assistant - 24x7*`;
}

/**
 * WhatsApp बॉट चालू करणारा मुख्य फंक्शन
 */
async function startWhatsAppBot() {
    // WhatsApp Session आणि Auth स्टेट लोड करा
    const { state, saveCreds } = await useMultiFileAuthState('auth_info_baileys');
    const { version } = await fetchLatestBaileysVersion();

    const sock = makeWASocket({
        version,
        auth: state,
        logger: pino({ level: 'silent' }), // अनावश्यक लॉग्स बंद ठेवण्यासाठी
        printQRInTerminal: false
    });

    // QR कोड आणि कनेक्शन स्टेटस हाताळणे
    sock.ev.on('connection.update', (update) => {
        const { connection, lastDisconnect, qr } = update;

        if (qr) {
            console.log('\n📱 खालील QR Code व्हॉट्सॲपवरून स्कॅन करा:\n');
            qrcode.generate(qr, { small: true });
        }

        if (connection === 'close') {
            const shouldReconnect =
                lastDisconnect?.error?.output?.statusCode !== DisconnectReason.loggedOut;
            console.log('❌ कनेक्शन बंद झाले. पुन्हा जोडण्याचा प्रयत्न करत आहे...', shouldReconnect);
            if (shouldReconnect) {
                startWhatsAppBot();
            }
        } else if (connection === 'open') {
            console.log('✅ WhatsApp बॉट यशस्वीरित्या सुरू झाला आहे आणि मेसेजसाठी तयार आहे!');
        }
    });

    // क्रिडेंशियल अपडेट झाल्यावर सेव्ह करणे
    sock.ev.on('creds.update', saveCreds);

    // येणारे मेसेजेस हाताळणे
    sock.ev.on('messages.upsert', async ({ messages, type }) => {
        if (type !== 'notify') return;

        for (const msg of messages) {
            // बॉटने स्वत: पाठवलेले मेसेजेस सोडून द्या
            if (!msg.message || msg.key.fromMe) continue;

            const fromJid = msg.key.remoteJid;
            const textMessage =
                msg.message.conversation ||
                msg.message.extendedTextMessage?.text;

            if (!textMessage) continue;

            const extractedUrl = extractUrl(textMessage);

            if (extractedUrl) {
                try {
                    // युझरला उत्तर पाठवा की प्रक्रिया सुरू आहे
                    await sock.sendMessage(fromJid, {
                        text: '⏳ *तुमची लिंक तपासली जात आहे... कृपया काही सेकंद वाट पाहा.*'
                    }, { quoted: msg });

                    // FastAPI Backend कडून विश्लेषित डेटा मागवा
                    const response = await axios.post(BACKEND_API_URL, {
                        url: extractedUrl
                    }, { timeout: 70000 });

                    const responseData = response.data;
                    const formattedMsg = formatResponse(responseData, extractedUrl);

                    // प्रतिमा आणि फॉरमॅट केलेला मजकूर युझरला पाठवा
                    if (responseData.image_url) {
                        await sock.sendMessage(fromJid, {
                            image: { url: responseData.image_url },
                            caption: formattedMsg
                        }, { quoted: msg });
                    } else {
                        await sock.sendMessage(fromJid, {
                            text: formattedMsg
                        }, { quoted: msg });
                    }

                } catch (error) {
                    console.error('API Calling error:', error.message);
                    await sock.sendMessage(fromJid, {
                        text: '❌ *माफ करा!* या वस्तूची माहिती मिळवताना अडचण आली. कृपया योग्य Amazon किंवा Flipkart लिंक पाठवल्याची खात्री करा.'
                    }, { quoted: msg });
                }
            } else if (textMessage.toLowerCase().trim() === 'hi' || textMessage.toLowerCase().trim() === 'hello') {
                await sock.sendMessage(fromJid, {
                    text: '👋 *Shopping AI मध्ये आपले स्वागत आहे!*\n\nमला कोणत्याही *Amazon* किंवा *Flipkart* मधील वस्तूची URL (Link) पाठवा. मी तुम्हाला त्या वस्तूची खरी किंमत, बनावट सवलत (Fake Discount) आणि कॅशबॅक माहिती काढून देईन.'
                }, { quoted: msg });
            }
        }
    });
}

import os

def generate_affiliate_url(raw_url: str) -> str:
    """
    Converts raw Amazon/Flipkart product URLs into monetized affiliate URLs.
    """
    if not raw_url:
        return raw_url

    parsed_url = urllib.parse.urlparse(raw_url)

    # 1. Amazon India Affiliate Tag Injection
    if "amazon" in parsed_url.netloc.lower():
        query_params = urllib.parse.parse_qs(parsed_url.query)
        query_params['tag'] = [AMAZON_AFFILIATE_TAG]
        new_query = urllib.parse.urlencode(query_params, doseq=True)
        return urllib.parse.urlunparse((
            parsed_url.scheme,
            parsed_url.netloc,
            parsed_url.path,
            parsed_url.params,
            new_query,
            parsed_url.fragment
        ))

    # 2. Flipkart / Other Stores via Cuelinks or EarnKaro Integration
    elif "flipkart" in parsed_url.netloc.lower():
        encoded_url = urllib.parse.quote(raw_url)
        return f"https://links.cuelinks.com?id={CUELINKS_PUB_ID}&url={encoded_url}"

    return raw_url

B. API Service (app/lib/services/api_service.dart)
Dart
import 'dart:convert';
import 'package:http/http.dart' as http;
import '../models/product_model.dart';

class ApiService {
  // Replace with your local IP when testing on a physical device (e.g., http://192.168.1.100:8000)
  static const String baseUrl = 'http://10.0.2.2:8000/api/v1';

  static Future<Product> analyzeProductUrl(String url) async {
    final uri = Uri.parse('$baseUrl/product/analyze');
    
    final response = await http.post(
      uri,
      headers: {'Content-Type': 'application/json'},
      body: jsonEncode({'url': url}),
    );

    if (response.statusCode == 200) {
      final Map<String, dynamic> jsonResponse = jsonDecode(response.body);
      return Product.fromJson(jsonResponse);
    } else {
      throw Exception('Failed to analyze link. Please verify the URL.');
    }
  }
}

    final url = _urlController.text.trim();
    if (url.isEmpty) return;

    setState(() {
      _isLoading = true;
      _errorMessage = null;

    }
